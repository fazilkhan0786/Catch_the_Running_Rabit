# The Chase Never Ends

A fast-paced browser game where every jump matters. Help a fearless rabbit outrun a relentless dog while collecting carrots along the way. The longer you survive, the faster your reflexes are tested. Built entirely with HTML, CSS, and JavaScript, the game delivers a lightweight arcade experience that runs directly in the browser without any external game engine.

# Story

A hungry dog is chasing an adventurous rabbit through an endless landscape. Your mission is simple but challenging. Jump over obstacles, avoid getting caught, collect as many carrots as possible, and survive for as long as you can. There is no finish line because the adventure never ends.
